# Beauty Studio — Онлайн-запис та CRM для салону краси

Сучасна модульна веб-система онлайн-запису клієнтів (у стилі Altegio) та CRM для салону краси. Працює на чистому JavaScript (ES Modules), PHP 8+ та реляційній базі даних **SQLite (PDO)**.

---

## 🌟 Ключові можливості системи

### 1. Трирівнева система розкладу (3-Level Schedule Engine)
Пріоритет розрахунку доступності: `DateOverrides` > `WeeklySchedule` > `Bookings / TimeBlocks`.
- **Рівень 1: Стандартний шаблон тижня (`weeklySchedule`)**:
  - Індивідуально для кожного майстра на 7 днів (Пн–Нд).
  - Налаштування тумблерів «Робочий / Вихідний», робочого інтервалу (`workStart` – `workEnd`) та регулярних перерв (`regularBreaks`, наприклад, обід 13:00–14:00).
- **Рівень 2: Винятки на конкретні дати (`dateOverrides` & `timeBlocks`)**:
  - `dateOverrides`: повний вихідний (`day_off`) або змінені робочі години (`custom_hours`). Повністю перекриває шаблон тижня на обраний день.
  - `timeBlocks`: разові відлучки, особистий час або технічні паузи (`date`, `startTime`, `endTime`, `reason`).
- **Рівень 3: Записи клієнтів та технічні буфери (`appointments`)**:
  - Розрахунок зайнятості: $\text{TotalNeeded} = \sum \text{Duration} + \text{Buffer}$.
  - Технічний буфер (`bufferTime`, 10–15 хв) після послуги на провітрювання та дезінфекцію.
  - Налаштування кроку часової сітки онлайн-запису майстра (`slotStep`: 15, 30, 60, 90 хв).

### 2. Календар розкладу (3 режими перегляду)
- **День**:
  - Почасова сітка (08:00–21:00) з режимами «Всі майстри» (колонки для кожного майстра) або фільтром по конкретному майстру.
  - Навігація кнопками «← День назад» / «День вперед →» з кроком у **1 день**.
  - **Інформативні картки записів**: відображають **Ім'я клієнта**, **Номер телефону** та **Короткий опис наданих послуг**.
  - **Персональні кольори послуг**: кожна послуга підсвічується власним кольором (кольоровий лівий маркер, плашка назви, бейдж).
  - **Багатослотові процедури**: для процедур тривалістю 60–120 хв наступні слоти позначаються як блоки продовження (`↳ Продовження: [Клієнт] до [Час]`), унеможливлюючи накладання нових записів.
  - **Заміна обіду**: якщо адміністратор підтвердив запис на час обіду майстра, плашка запису замінює «☕ Обідня перерва».
  - Візуальні блоки візитів клієнтів з окремим нижнім штрих-блоком технічного буфера.
  - Карточки перерв (TimeBlocks) з позначкою причини.
  - Розрахунок виручки за день з розбивкою по майстрах та загальної суми.
- **Тиждень**:
  - 7 колонок (Пн–Нд).
  - Карточки візитів забарвлені у відповідний колір послуги.
  - Спокійний сірий фон на вихідні дні майстра.
  - Зручний огляд завантаженості та клік по вільному часу для додавання запису.
- **Місяць**:
  - Сетка на 5–6 тижнів з компактними плашками робочих змін (наприклад, `Св: 09–20`, `Мр: Вих`) та кількістю записів.
  - Швидкий перехід у режим «День» по кліку на будь-яку дату.

### 3. Детектор конфліктів, захист від накладання та робота з обідом
- **Суворий захист від накладання (Overlap Protection)**:
  - Враховується точний хронометраж процедури: якщо запис розпочато о 14:00 тривалістю 60 хв, неможливо створити запис на 14:30.
  - Як у клієнтському віджеті, так і в адмін-панелі перевіряються перетини часових інтервалів $[Start_1, End_1) \cap [Start_2, End_2)$.
- **Розумне перенесення на час обіду**:
  - З панелі адміністратора дозволено призначати або переносити запис на обідній час майстра.
  - При цьому з'являється діалогове підтвердження: *«Обраний час перетинається з обідом майстра. Замінити обід цим записом?»*.
  - У разі відповіді «Так» запис успішно зберігається, а напис «☕ Обідня перерва» приховується на користь клієнтського запису.
- При зміні графіка на день або додаванні перерви система миттєво перевіряє перетин з існуючими записами клієнтів.
- Модальне вікно конфліктів дозволяє в 1 клік:
  - **Перенести запис** на інший час/день.
  - **Скасувати запис** із відправкою сповіщення клієнту.
  - **Залишити як виняток**.

### 4. Повноцінна клієнтська база (CRM)
- Каталог клієнтів із автоматичним формуванням за номерами телефонів.
- **Фільтр клієнтів за майстрами** (Світлана, Марія або всі).
- **Фільтр за датою візиту**.
- **Групування історії записів за один день**: якщо клієнт робив кілька послуг в один день, вони об'єднуються в один компактний блок із загальною сумою чека.

### 5. Реляційна база даних SQLite (PDO)
- Усі дані зберігаються виключно в реляційній базі даних **SQLite** (`data/salon.sqlite`).
- **Транзакції (ACID)**: гарантують цілісність даних при одночасних записах клієнтів.
- **Режим WAL (Write-Ahead Logging)**: дозволяє клієнтам читати та записувати дані паралельно без блокувань.
- **Швидкі B-Tree індекси**: вибірки за датою, телефоном клієнта чи майстром виконуються за частки мілісекунди навіть при десятках тисяч записів.
- **Початкова база в комплекті**: дефолтні налаштування салону, майстри, послуги та первинні записи вже внесені в базу та розгортаються миттєво.

### 6. Модуль Telegram-сповіщень та Telegram-бот (`bot.php`)
- **Миттєві сповіщення про новий запис**:
  - Сповіщення надходить майстру на його персональний Chat ID.
  - Одночасно надсилається адміністратору салону.
  - Черга та журнал сповіщень зберігаються в таблиці `telegram_queue`.
- **Кнопка перевірки зв'язку**: кнопка «✈️ Надіслати тест у Telegram» у розділі налаштувань для швидкої перевірки токена.
- **Telegram-бот для перегляду розкладу (`bot.php`)**:
  - `/start` — привітання, відображення Telegram Chat ID користувача, інтерактивне меню кнопок.
  - `📅 Записи на сьогодні` (або `/today`) — гарно сформатований список усіх клієнтів на сьогодні по майстрах із сумою та статусами.
  - `🗓 Записи на завтра` (або `/tomorrow`) — розклад на завтрашній день.
  - `📊 Статистика за місяць` (або `/stats`) — виручка, кількість візитів та нових клієнтів за місяць.
  - `/find <номер>` — швидкий пошук останніх візитів клієнта за номером телефону.
  - `ℹ️ Мій Chat ID` — допомагає майстрам дізнатися свій ID для вставки в профіль.

### 7. Пряма інтеграція з Google Calendar (Service Account) та iCal
- **Миттєва двостороння синхронізація через Google Service Account**:
  - Записи створюються, переносяться та видаляються в Google Календарі **в реальному часі без затримок** (на відміну від iCal, який оновлюється раз на добу).
  - Працює у фоновому серверному режимі (Server-to-Server) за допомогою підписаного JWT (OAuth2) без потреби авторизації кожного майстра через браузер.
  - Синхронізуються кольори послуг за допомогою `colorId` Google Calendar API.
  - Підтримка персональних календарів майстрів або загального календаря салону.
  - Кнопка **«🗓 Перевірити Google Calendar»** прямо в розділі налаштувань для швидкої діагностики доступу.
- **Персональний потік iCal для майстрів**: посилання виду `api-v2.php?action=ical&master=m1&key=key_m1_svitlana` для підписки в iOS Calendar / Mac.
- **Експорт для клієнтів**: на 5 кроці онлайн-запису доступні кнопки **«Додати в Google Calendar»** та **«Додати в Apple Calendar»** (`.ics`).

### 8. Захист від ботів та верифікація клієнтів
- **Honeypot-пастка**: приховані поля у формі бронювання, які заповнюють спам-боти, блокують автоматичні спам-запити без зайвого клопоту для клієнтів.
- **Валідація виключно українських мобільних номерів**:
  - Приймаються лише номери у форматі `+380` або `0`.
  - Сувора перевірка дійсних кодів українських мобільних операторів (Київстар: 67, 68, 96, 97, 98, 77; Vodafone: 50, 66, 95, 99; lifecell: 63, 73, 93; ТриМоб/PEOPLEnet/Інтертелеком: 91, 92, 94).
- **Верифікація запису через Email**:
  - При реєстрації обов'язково зазначається електронна пошта.
  - На вказану адресу відправляється лист із персональним токеном та посиланням на підтвердження (`api-v2.php?action=verify_booking&token=...`).
  - Після переходу за посиланням запис переходить у статус підтвердженого, активується подія в Google Календарі та надсилається сповіщення майстру.

### 9. Індивідуальні кольори послуг
- У розділі «3. Перелік послуг, ціни та буфери» кожна послуга має можливість прив'язки індивідуального кольору з палітри:
  - `#63ade2` (Ніжно-блакитний)
  - `#ced65a` (Оливковий / Салатовий)
  - `#ba82c8` (Бузковий / Фіолетовий)
  - `#f2be8a` (Персиковий / Теплий)
  - `#ebacd3` (Рожевий)
- Обраний колір відображається:
  - У списку послуг у налаштуваннях (кольоровий індикатор).
  - У розкладі календаря (акцентні смуги та бейджі).
  - В Google Календарі (події забарвлюються відповідним `colorId`).

### 10. Захист від кешування та Live-синхронізація
- Заголовки `Cache-Control: no-cache, no-store, must-revalidate` та параметри `?_t=...` запобігають застаріванню сторінок у браузерах.
- **Auto-Sync**: фонова перевірка змін кожні 15 секунд та миттєве оновлення розкладу при перемиканні вкладок браузера чи розблокуванні смартфона.
- **Контроль з'єднання**: у разі відсутності зв'язку з сервером будь-які дії користувача блокуються з попередженням про помилку збереження.

## 🚀 Розгортання на VPS сервері (Ubuntu / Debian)

### 1. Системні вимоги
- **ОС**: Ubuntu 20.04 / 22.04 / 24.04 або Debian 11 / 12
- **Вебсервер**: Apache 2.4 або Nginx
- **PHP**: версія 8.0 або вище
- **Критично обов'язкові модулі PHP**:
  - `php-sqlite3` (або `php8.x-sqlite3`) — **обов'язково для роботи бази даних SQLite (PDO)**!
  - `php-curl` — для надсилання сповіщень у Telegram API.
  - `php-mbstring` — для коректної роботи з україномовним текстом (UTF-8).

---

### 2. Встановлення пакетів на сервері

#### Для веб-сервера Apache:
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y apache2 php php-sqlite3 php-curl php-mbstring git
sudo systemctl enable apache2
sudo systemctl restart apache2
```

#### Для веб-сервера Nginx:
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y nginx php-fpm php-sqlite3 php-curl php-mbstring git
```

---

### 3. Клонування репозиторію та налаштування прав

Перейдіть у каталог веб-сервера (наприклад, `/var/www/html` або `/var/www`):

```bash
cd /var/www/html
sudo git clone https://github.com/Maksxxx8/servis.git
cd servis
```

**Критично важливий крок — налаштування прав доступу до каталогу бази даних `data/`**:
Веб-сервер (`www-data`) повинен мати право запису у каталог `data` та файл `salon.sqlite`:

```bash
sudo chown -R www-data:www-data data
sudo chmod -R 775 data
```

---

### 4. Конфігурація віртуального хоста

#### Варіант А: Apache (якщо використовується Apache)
Увімкніть модуль `mod_rewrite` та дозвольте `.htaccess`:
```bash
sudo a2enmod rewrite headers
sudo systemctl restart apache2
```

#### Варіант Б: Nginx (`/etc/nginx/sites-available/servis`)
```nginx
server {
    listen 80;
    server_name your-domain.com; # або IP-адреса вашого VPS

    root /var/www/html/servis;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/var/run/php/php-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }

    # Захист файлу бази даних від прямого скачування через браузер
    location ^~ /data/ {
        deny all;
        return 403;
    }
}
```
Активація конфігурації:
```bash
sudo ln -s /etc/nginx/sites-available/servis /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

### 5. Перевірка працездатності (Діагностика)

Відкрийте у браузері посилання діагностики сервера:
👉 **`http://your-domain.com/api-v2.php?action=diagnostic`** (або замініть на ваш IP: `http://91.204.120.134/servis/api-v2.php?action=diagnostic`).

У відповіді має відобразитися:
```json
{
    "status": "ok",
    "database": {
        "status": "ok",
        "engine": "SQLite (PDO)",
        "db_file_exists": true,
        "db_writable": true
    },
    "php_user": "www-data"
}
```
Якщо горить `"status": "ok"` — базу підключено успішно, розклад та записи клієнтів працюватимуть стабільно!

### 6. Налаштування Telegram-бота

1. **Отримання токена**:
   - Відкрийте [@BotFather](https://t.me/BotFather) у Telegram, надішліть `/newbot` та створіть нового бота.
   - Скопіюйте отриманий токен (наприклад, `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`).
2. **Збереження токена в CRM**:
   - Увійдіть в адмінку (PIN-код за замовчуванням: **`1234`**).
   - Перейдіть у розділ **«Налаштування»**.
   - Вставте токен у поле **«Telegram Bot Token»**.
3. **Дізнатися свій Chat ID**:
   - Надішліть щойно створеному боту команду `/start`.
   - Бот відповість повідомленням із вашим **Chat ID**.
   - Скопіюйте цей Chat ID та вставте його у поле **«Telegram Chat ID адміністратора»** (або у профіль відповідного майстра).
   - Натисніть кнопку **«✈️ Надіслати тест у Telegram»** — вам одразу надійде тестове повідомлення.
4. **Активація інтерактивного бота (Webhook)**:
   - Щоб бот відповідав на кнопки `/today` (записи на сьогодні) та `/stats`, увімкніть Webhook, відкривши посилання у браузері:
     👉 **`http://your-domain.com/bot.php?action=set_webhook`**
   - У відповідь Telegram повідомить: `{"ok":true,"result":true,"description":"Webhook was set"}`.

### 7. Налаштування прямої синхронізації з Google Calendar (Service Account)

1. **Права на файл ключа на сервері**:
   Файл ключа сервісного аккаунту повинен бути доступний для читання веб-сервером (`www-data`):
   ```bash
   sudo chmod 755 /path/to
   sudo chmod 644 /path/to/service-account.json
   ```

2. **Надання доступу до календаря майстра / салону**:
   - Відкрийте файл ключа або подивіться поле `client_email` (наприклад, `xxx@servis-calendar-sync-514520.iam.gserviceaccount.com`).
   - Відкрийте [Google Календар](https://calendar.google.com/).
   - У лівій колонці знайдіть потрібний календар (наприклад, «Світлана» або основний календар салону) -> натисніть три крапки **⋮** -> **«Налаштування та спільний доступ»**.
   - Перейдіть у блок **«Доступ для окремих користувачів або груп»** -> натисніть **«Додати людей та групи»**.
   - Вставте email сервісного аккаунту та оберіть рівень дозволів: **«Внесення змін до подій»** (Make changes to events).
   - Натисніть **Надіслати**.

3. **Підключення в адмінці CRM**:
   - У розділі **«Налаштування»** введіть Google Calendar ID (для персонального календаря майстра це зазвичай його email `master@gmail.com`, або ID спільного календаря).
   - Натисніть кнопку **«🗓 Перевірити Google Calendar»**.
   - Система перевірить зв'язок і повідомить `Доступ надано (OK)`.

Тепер будь-який створений запис або перенесення часу миттєво з'явиться в Google Календарі на телефоні майстра!
