# Beauty Studio — Модульний фронтенд

Модульна архітектура фронтенду для системи онлайн-запису та панелі керування салоном краси, побудована за принципами та структурою **EasyAppointments** з підтримкою всієї функціональності та полів з `index-v2.html`.

---

## 📁 Структура проєкту

```text
frontend/
├── index.html                  # Каркас сторінки, контейнери видів та модальні вікна
├── css/
│   └── styles.css              # Базові стилі та допоміжні класи
└── js/
    ├── app.js                  # Головна точка входу (bootstrap додатку)
    ├── config.js               # Початкові налаштування та конфігурація салону
    ├── state.js                # Централізований реактивний стан (state/store)
    │
    ├── http/                   # Шар взаємодії з бекендом (за зразком EasyAppointments HTTP clients)
    │   └── api-client.js       # Завантаження/збереження даних через api-v2.php + fallback в localStorage
    │
    ├── utils/                  # Допоміжні утиліти
    │   ├── dom.js              # Хелпери роботи з DOM ($, $$, show, hide, toggle)
    │   ├── time.js             # Розрахунок слотів часу, конвертація хвилин
    │   └── format.js           # Форматування цін, дат та телефонів
    │
    ├── components/             # Перевикористовувані компоненти та модальні вікна
    │   ├── admin-bar.js        # Верхня панель адміністратора (перемикання видів, бейдж сервера)
    │   ├── pin-modal.js        # Модальне вікно входу за PIN-кодом
    │   ├── service-modal.js    # Модальне вікно додавання/редагування послуги
    │   └── booking-modal.js    # Модальне вікно картки запису та ручного запису на шахівниці
    │
    └── pages/                  # Контролери сторінок/видів
        ├── booking.js          # Клієнтський віджет запису (стиль Altegio, 5 кроків)
        ├── calendar.js         # Шахівниця розкладу майстрів, підрахунок виручки
        ├── settings.js         # Налаштування салону, профілі майстрів та прайс-лист
        └── clients.js          # База клієнтів та історія записів
```

## 🚀 Переваги для масштабування (порівняно з одним файлом)

1. **Ізольованість модулів:**
   - Кожен екран (`booking`, `calendar`, `settings`, `clients`) знаходиться в окремому файлі.
   - Модальні вікна винесені в папку `components/` і не засмічують логіку сторінок.
   
2. **Єдине джерело правди (`state.js`):**
   - Усі модулі працюють з єдиним об'єктом стану через патерн Observer (`subscribe` / `notify`).
   - При оновленні бази даних автоматично перемальовуються відкриті вкладки.

3. **Гнучкий шар API (`http/api-client.js`):**
   - Автоматично визначає адресу бекенду (`api-v2.php`).
   - Якщо бекенд тимчасово недоступний, система прозоро зберігає все в `localStorage` та повідомляє користувача через бейдж статусу.
   - Підтримка сповіщень у Telegram при створенні нового запису.

4. **Чистий HTML (`index.html`):**
   - Ніяких вбудованих `<script>` або спагетті-коду.
   - Всі обробники подій підключаються декларативно через `data-action` або ініціалізатори модулів.
   - Сучасні ES Modules (`<script type="module" src="js/app.js"></script>`).

## 🔧 Як запустити

Відкрийте проєкт через будь-який локальний вебсервер (наприклад, Apache, Nginx або вбудований сервер PHP / Live Server у VS Code / Python):

```bash
# Приклад запуску з кореня репозиторію:
python3 -m http.server 8000
```

Після цього відкрийте у браузері:
- Клієнтський віджет: `http://localhost:8000/frontend/`
- Прямий вхід у режим майстра: `http://localhost:8000/frontend/?admin=1` (PIN за замовчуванням: `1234`)
